How real NOAA satellite images could be added later
  1. Download satellite images for your weather station's area and dates from NOAA (for example the GOES imagery pages at star.nesdis.noaa.gov/GOES). Check the site for the download options currently offered.
  2. Name each image with its date, such as 2023-07-15.png, so it can be matched with the weather table.
  3. Turn every image into a few numbers (for example average brightness or the share of bright cloud pixels).
  4. Add those numbers as new columns next to the weather data.
  5. Train the model again and compare its test error with the model that uses no images. Only if the error improves can you say the satellite data helps.
Until these steps are done and tested, this project does not predict rainfall from satellite images.
