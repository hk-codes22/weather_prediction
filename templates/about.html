About This Project

Weather Prediction Using Satellite Images: a college project that estimates rainfall from weather readings.

Important: this is a student learning project. Its rainfall values are model estimates, not an official weather forecast, and must not be used for safety or planning decisions. Please check your national weather service for real forecasts.
Project objectives
  • Load, clean and explore historical weather data with Pandas and NumPy.
  • Show rainfall, temperature and humidity trends and monthly patterns as charts.
  • Train and evaluate a simple machine learning model that estimates rainfall.
  • Let users enter weather readings and see an estimate with a clear warning about its limits.
  • Upload and inspect satellite images, and explain how they could be used in future work.
  • Practise responsible AI: honest evaluation, clear limitations, and demo data labelled as demo data.

Dataset information
The built-in sample file (data/sample_weather.csv) is demonstration data, not real NOAA observations. It was generated by the script make_sample_data.py with a seasonal pattern and random variation, so that the application runs straight away. Results from this file say nothing about real weather.

The application expects a CSV file with these columns (units in brackets):

date (YYYY-MM-DD), temperature (°C), humidity (%), pressure (hPa), wind_speed (km/h), rainfall (mm per day)

Where to get real NOAA data

  • NOAA NCEI Climate Data Online: search and download daily weather observations from stations around the world.
  • NOAA NCEI Past Weather: find a station on a map and view its daily data (from the GHCN-Daily dataset).
  • Global Summary of the Day (GSOD): daily files per station and year. They include mean temperature, dew point, pressure, wind speed and precipitation. This is the closest NOAA product to the columns this project needs.
  • NOAA GOES Image Viewer: satellite images, for the future satellite feature.

Using real data in this project

  1. Download a GSOD CSV file for one station and year range.
  2. Convert it with the helper script: python convert_noaa.py downloaded_file.csv data/my_station.csv. It changes the units (Fahrenheit to °C, knots to km/h, inches to mm) and calculates humidity from the dew point.
  3. Upload the converted file on the Weather Data page, then click Retrain on the Prediction page.
GSOD has no direct humidity value, so humidity here is calculated from temperature and dew point. Some stations do not record every column or leave out days with no rain, so check the missing-value table after uploading.
How the prediction model works
  1. Load and clean: read the CSV, convert dates and numbers, remove duplicate rows, fill missing numbers with the column median.
  2. Choose inputs and target: inputs are temperature, humidity, pressure and wind speed. The target is rainfall in mm.
  3. Split by time: the oldest 80% of days are used for training, the newest 20% for testing. The model never sees the test days while learning.
  4. Train: a Random Forest Regressor builds 100 small decision trees and averages their answers. If the file has fewer than 100 rows, only a simple "average rainfall" baseline is used.
  5. Evaluate: MAE (average error in mm) and RMSE (like MAE, but large errors count more) are measured on the test days and compared with the baseline that always predicts the average.
  6. Save and use: the model is saved with Joblib. The Prediction page loads it and estimates rainfall for the four numbers entered.

Estimating vs. forecasting: this model estimates how much rain goes with a set of current conditions. A forecast would predict future days from the history of past days, which this version does not do.

Satellite images: the model does not learn from satellite images. The Satellite page only shows an uploaded image and measures it.

Current limitations
  • The sample data is synthetic, so the reported errors do not describe real-world performance.
  • Rain is hard to predict: most days have no rain, and the model is weakest on heavy-rain days.
  • The model estimates rainfall from the same day's readings. It is not a forecast of future weather.
  • It was trained on one dataset (and, with real data, one station), so it may not work in other places or climates.
  • Only four inputs are used. Clouds, wind direction, season and nearby stations are ignored.
  • Very small or very unusual datasets can give unreliable models, so always read the test errors on the Prediction page.
  • The rainfall categories use simple thresholds chosen for this project, not official ones.
Future improvements
  • Train on several years of real NOAA data from a chosen station.
  • Forecast future rainfall using lagged values (previous days' rainfall and weather) and time-series methods.
  • Compare more models, for example linear regression and gradient boosting, using time-series cross-validation.
  • Turn satellite images into numbers (such as cloud brightness) and test whether they improve the error.
  • Predict "rain / no rain" as a separate classification task.
  • Add a database and user accounts if the project grows.
